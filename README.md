# k2prep has moved

k2prep is now part of [dataset_tools](https://github.com/aoleg/dataset_tools), in the [k2prep](https://github.com/aoleg/dataset_tools/tree/main/k2prep) folder, with its full history. It is developed there; this repository is archived and gets no more changes.

In dataset_tools all tools share one virtual environment in the repository root. Run `install.bat` in the `k2prep` folder to create it, then use `run.bat` and `cleanup.bat` as before. The documentation is the [k2prep README](https://github.com/aoleg/dataset_tools/blob/main/k2prep/README.md).
